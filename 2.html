STEP 32차시 · 68~72분

웹앱을 index.html 파일로 저장하기버셀에 올리려면 Canvas 안의 앱을 내 컴퓨터 파일로 꺼내야 해요

  1. 바탕화면에 my-app 폴더 만들기마우스 오른쪽 → 새로 만들기 → 폴더 (영어 이름!)
  2. Canvas 오른쪽 위 [코드] 보기 → 코드 칸 클릭 → Ctrl + A → Ctrl + C
  3. 메모장 열고 Ctrl + V 붙여넣기
  4. [파일] → 다른 이름으로 저장 → my-app 폴더 → 이름 index.html파일 형식: 모든 파일 · 인코딩: UTF-8
  5. index.html을 더블클릭 → 크롬에서 앱이 열리면 성공!

왜 이름이 꼭 index.html?

웹사이트의 첫 페이지(현관문)라는 약속된 이름이에요. 이름이 다르면 주소를 열었을 때 빈 화면이 나와요.
